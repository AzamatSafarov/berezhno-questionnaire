- Admin Excel: 5 sheets, неполная синтетическая запись исключена.
- 320/360/390/430/768/1440px: все 10 методик, keyboard radio, summary, admin login; no overflow.
- При сборке обнаружены повторные загрузки research-live.js/Supabase scripts в исходном index.html. В переносимом репозитории удалены дубликаты, browser pageerrors проверены.
- Supabase read-only: migration history, research functions и их ACLs прочитаны; collection_enabled=false.

## Не проверено / осталось
- Replay всех миграций на новом чистом Supabase: не выполнен. Docker не установлен на машине подготовки; отдельный облачный проект не создавался. SQL пакета — подготовленные миграции, не заявление о проверенном полном клоне бэкенда.
- SMTP не настроен/не подтверждён. Ошибка rate limit была фактической. Auth redirects пользователь исправил, но реальный успешный вход после этого не подтверждён.
- Полное invited server completion именно из нового репозитория не выполнялось; локальные браузерные проверки не заменяют серверные.
- Auto retention deletion не настроено. Согласие требует согласования с реальным storage/privacy. Реальный сбор остаётся выключенным.
- scoring кроме MSPSS не подключён. Supplied WAS/DAS/PASS-R требуют сверки; PDQ и TOB mapping нужно добавить из источника.
- GitHub private repo не подключён к текущему Vercel deployment автоматически.
